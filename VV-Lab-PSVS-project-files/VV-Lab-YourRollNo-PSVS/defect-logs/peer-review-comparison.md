# Peer-Review Comparison

Complete this file after exchanging defect logs with a classmate. Do not invent the classmate's findings.

| Item | Value |
|---|---|
| Your detected defect IDs | To be completed |
| Classmate's detected defect IDs | To be completed |
| Intersection (defects detected by both) | To be completed |
| Union (all distinct defects found by either) | To be completed |
| Defects missed by you | To be completed |
| Detection rate | Your defects ÷ union = to be calculated |

## Calculation

Detection rate = number of defects found in your log ÷ number of distinct defects in the union of both logs.

## Defects Missed

List the classmate's defect IDs that are not in your log and record them here after the peer review.
