# Glossary

| Term | Definition |
|---|---|
| Depositor | A registered institution that deposits seed boxes. |
| Box | A sealed container holding seed samples of one species. |
| Chamber | A freezer storage area with a defined capacity and temperature. |
| Species | The biological species represented by a seed sample. |
| Vault authority | The authority permitted to authorize emergency release. |
| Custody | Responsibility for safeguarding a box without owning it. |
| Accession | The act of formally accepting and recording a deposited box. |
| Deposit | Acceptance of a box into vault storage. |
| Withdrawal | Release of a stored box from vault custody. |
| Redeposit | Returning a previously withdrawn box to storage after re-inspection. |
| Re-inspection | Inspection performed before a withdrawn box can be redeposited. |
| Emergency | A declared situation in which the emergency release rule may apply; declaration details require clarification. |
| Viability | The ability of seed samples to remain capable of germination. |
| Low viability | Viability below a defined threshold; the threshold requires clarification. |
| Maintenance window | An authorized period in which chamber maintenance is performed. |
| Registration | Recorded confirmation that an institution is an eligible depositor. |
| Owner | The depositor that retains legal ownership of a box. |
| Stored | A box currently held in a chamber. |
| Withdrawn | A box released from vault storage. |
| Quarantined | A box withheld from normal storage or release pending a required check. |
